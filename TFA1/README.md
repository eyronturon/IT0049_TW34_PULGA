# A Point-of-Sale System
The project containts a basic four-page Point-of-Sale system built with CodeIgniter 4!

# Features
- Landing page
- About page
- Customer Accounts page
- User Accounts page
- Navigation between all pages
- Static PHP arrays for the customer and user records

# Requirements

- PHP 8.2 or higher
- Composer
- XAMPP or another PHP server
- CodeIgniter 4
